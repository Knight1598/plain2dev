# Token discipline

Optimize total work to an accepted, verified outcome. Read evidence progressively; avoid reprinting unchanged requirements, cards, logs or duplicated code. Preserve constraints, validation, data-integrity requirements and uncertainty. Incorrect short prompts create rework.

Keep paths and short decisions for future retrieval. Report tokens only from actual provider usage. Characters/bytes/file counts are not token counts, especially across Thai and English. Never promise a saving percentage. Compare input/output usage including skill loading, questions, retries and tests together with acceptance quality; see the package benchmark protocol.
