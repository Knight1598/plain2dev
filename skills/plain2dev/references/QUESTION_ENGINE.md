# Question engine

Before asking: can repository evidence answer this, is there a safe reversible default, and would different answers materially alter correctness, data handling, cost or workflow?

Ask the smallest useful set, normally 1–3 per round, in everyday language. Do not ask for framework/database/pixel details already supplied by project conventions.

Useful: “ตัดสต๊อกทันทีที่ส่งคำขอ หรือหลังหัวหน้าอนุมัติ?” Do not ask when already answered. Do not repeat permission requests for authorized work. “ตัดสินใจให้เลย” permits choosing/disclosing reversible defaults, not inventing confirmed business facts or expanding external actions.

Keep a draft explicit while waiting on a blocker and continue independent work. Incorporate corrections without restarting the interview.
